# So sánh Markdown và HTML

## Phần 2. So sánh và đánh giá

### 1. So sánh Markdown và HTML

| Tiêu chí | Markdown | HTML |
|---|---|---|
| Số lượng ký tự | Ít, ngắn gọn | Nhiều hơn |
| Độ dễ đọc | Dễ đọc, dễ hiểu | Khó đọc hơn khi có nhiều thẻ |
| Token | Thường tiết kiệm Token với nội dung đơn giản | Có thể sử dụng nhiều Token hơn |
| Mục đích sử dụng | Viết tài liệu, câu trả lời cho AI | Xây dựng giao diện web |

### 2. Giải pháp cho hệ thống GreenTech

GreenTech nên sử dụng Markdown làm định dạng chính vì Markdown dễ đọc, dễ viết và có cú pháp ngắn gọn. Điều này giúp giảm lượng dữ liệu định dạng cần xử lý, từ đó có thể tiết kiệm Token và chi phí khi AI trả lời câu hỏi của người nông dân.

HTML chỉ nên sử dụng khi cần xây dựng giao diện web hoặc định dạng nội dung phức tạp.
